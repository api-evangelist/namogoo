# Namogoo

> Namogoo Technologies Ltd. (operating as Wandz.ai) is an Israeli commerce-technology company
> founded in 2014. It began with Customer Journey Hijacking prevention, moved on to Digital
> Journey Continuity and Intent-Based Promotions for online retailers, then pivoted to
> real-time predictive AI for the customer experience under the Wandz.ai brand. AB Tasty
> acquired Wandz.ai in November 2025 and the technology now powers AB Tasty AdaptiveCX.
>
> Namogoo publishes NO public REST API, OpenAPI definition, GraphQL endpoint, MCP server or
> A2A agent card. Integration is a JavaScript tag plus first-party mobile SDKs, activated with
> an Account ID issued by the vendor through a contact-sales flow. This file was generated by
> API Evangelist from probed public sources; it is not published by the company.

## SDKs and packages

- [wandz-android-sdk](https://github.com/namogoo/wandz-android-sdk): Kotlin SDK, `ai.wandz.android:core-wandz` 1.0.49 on Maven Central.
- [wandz-ios-sdk](https://github.com/namogoo/wandz-ios-sdk): Swift Package Manager binary target `WandzSDK` (iOS 15+).
- [NamogooIBPSDK](https://cocoapods.org/pods/NamogooIBPSDK): Intent-Based Promotions iOS SDK on CocoaPods, MIT.
- [namogoo/module-intentbasedpromotion](https://packagist.org/packages/namogoo/module-intentbasedpromotion): Magento 2 module.
- [namogoo/module-predictiveincentive](https://packagist.org/packages/namogoo/module-predictiveincentive): Magento 2 module.
- [GitHub organization](https://github.com/namogoo): 10 public repositories.
